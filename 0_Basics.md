# Bias and Variance

- Bias is an error caused by oversimplifying the relationship between input features and target variables, leading to a less complex model.
- Variance is an error caused by a model learning the training data too closely, including noise and random fluctuations, resulting in a more complex model.

| Bias | Variance | Model Behavior             | Result       |
|-------|----------|---------------------------|--------------|
| High  | High     | Too simple and unstable   | Very Poor    |
| High  | Low      | Too simple                | Underfitting |
| Low   | High     | Too complex               | Overfitting  |
| Low   | Low      | Learns actual pattern well| Best Model   |

# Machine Learning

- **Definition:** Machine Learning is the process of building algorithms using historical data to identify patterns and make predictions or decisions.

```text
Collect Data → Train Model → Create Predictive Model → Make Predictions
```

# Types of Machine Learning

| Type                   | Data         | Goal                 | Algorithms |
|------------------------|--------------|----------------------|------------|
| Supervised Learning    | Labeled Data | Predict Output       | Linear Regression, Logistic Regression, Decision Tree, Random Forest |
| Unsupervised Learning  | Unlabeled Data | Find Patterns/Groups | K-Means Clustering, Hierarchical Clustering |
| Reinforcement Learning | Reward-Based | Learn Best Actions   | Q-Learning, Deep Q-Network (DQN), RVI Q-Learning |
